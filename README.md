# GART Draw

Aplicación de escritorio para Windows para dibujar diagramas y planos con medidas reales: formas, galerías propias, reglas, cajas de medidas y calculadores sobre el lienzo.

## Descargar

Descarga el instalador más reciente desde **[Releases](https://github.com/danieljordan1900-org/gart-draw-releases/releases/latest)**:

- `gart-draw-X.Y.Z-x64-setup.exe`: instalador recomendado
- `gart-draw-X.Y.Z-x64.msi`: instalador MSI

Una vez instalada, la app avisa sola cuando hay una versión nueva y se actualiza desde dentro.

## Novedades

Los cambios de cada versión están en [CHANGELOG.md](CHANGELOG.md). También se ven dentro de la app, en **Ayuda → Novedades**.
